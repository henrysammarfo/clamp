# Demo video script (≤ 3 minutes)

Tone: calm, clear, no hype. Show the refuse first.

## 0:00 to 0:20 · Open

On screen: CLAMP wordmark and soft line.

Voice:
“CLAMP is a delegation control layer for AI agents that spend. You set a temporary mandate. The agent can act alone only inside it.”

## 0:20 to 0:50 · Mandate

Show create mandate:
- purpose: office supplies
- budget including fees
- merchants: Amazon, Apple, Uber
- expiry tonight

Voice:
“This mandate is committed on Base Sepolia. The hash is on the audit trail.”

Cut to Basescan for one second if the tx link is ready.

## 0:50 to 1:20 · Block first

Submit: buy on BestBuy.

Show Block.
Show “nothing paid.”
Show request · rule · decision · reason · tx.

Voice:
“BestBuy is not on the list. Code stops it. Nothing paid. The refuse is on chain.”

## 1:20 to 1:45 · Allow

Submit: Amazon inside budget.

Show Allow and settlement or pay receipt path.
Show matching tx.

Voice:
“Same mandate. Amazon is allowed. The gate passes in code, not by asking the model for permission.”

## 1:45 to 2:15 · Needs human

Submit: Apple near the budget edge.

Show Needs human hold.
Approve.
Show final Allow receipt and tx.

Voice:
“Borderline cases wait for a person. No payment until then.”

## 2:15 to 2:40 · Efficiency

Show metrics panel if Song numbers are ready.
Else say:
“Parse once, gate in code, explain once. Fewer model calls than asking an LLM to judge every spend.”

## 2:40 to 3:00 · Close

Show audit trail handoff.

Voice:
“A second person can reconstruct the story from the trail alone. CLAMP. Control before action.”

End card: Team 14 · GitHub link · Base Sepolia contract address.
